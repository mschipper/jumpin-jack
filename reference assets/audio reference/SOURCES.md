## Pack notes

- Large source WAVs (Going Up, Jump Run Duck, Falling Rock source) were not shipped; compressed `.ogg` / `.mp3` used to stay under the chat attachment limit.
- Mixkit files are the free preview MP3s from Mixkit’s CDN (Mixkit License).
- `jump_plumber.mp3` was re-encoded from the CC0 FLAC via ffmpeg for easy `HTMLAudioElement` use.

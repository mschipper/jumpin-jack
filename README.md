# Jumpin' Jack

Educational vertical climber: jump to the platform with the greater number before the pad you are standing on gives way.

## Play

```bash
npm install
npm run dev
```

Open the URL Vite prints (default http://localhost:8080).

```bash
npm test
npm run build
```

Skip the setup menu with query params:

`?numbers=whole&difficulty=normal&mode=challenge`

Number types (`whole` / `decimal` / `fraction`), difficulties, and modes (`casual` / `challenge` / `speed`) are live. Casual wins at 20 with no timer. Challenge rests every 20. Speed run has no breaks and a louder timer.

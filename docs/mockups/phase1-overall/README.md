# Phase 1 — overall look (pick one)

Three directions for the in-game screen. Same layout in all three: centered play column, HUD (platforms / level / best / pause / timer), numbers **below** the pads, Foozle robot, desktop sky expanding on both sides.

| Option | Thesis |
|---|---|
| **A · Toybox Sky** | Saturday-morning cartoon. Grass-capped dirt pads, marshmallow clouds, hanging wooden number signs, navy pills, gold pause. Closest to Greater Heights, dressed up. |
| **B · Cloud Deck** | Airy educational toy. White floating decks with a cyan bar that matches the robot’s eyes, glass number plates, pale sky, slim HUD. Quietest; numbers are the loudest thing. |
| **C · Cut-paper Kite** | Construction-paper layers. Hard offset shadows, kite-stripe pad tops, manila tags, cobalt sky. Most graphic; timer is a kite stripe. |

You can mix later (e.g. Toybox world + Cloud Deck HUD), but pick a **home** for sky, pads, and HUD so the next rounds (platform numbers, menus, results) match.
